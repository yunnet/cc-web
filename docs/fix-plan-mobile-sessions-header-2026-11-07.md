**根因（代码行为，不是数据丢失）：**

1. 侧边栏在空间下只列**本浏览器打开着的**任务（`cc-web-tabs.ids`），空间列表却来自服务端。

3. 点 Open 后，没勾选的会话进入 `cc-web-tabs.ignoredIds`。从此这台设备刷新不再显示它们，也不再提示。
4. 两个空间的 6 个任务都是在 PC 上新建的（11-04、11-05），对手机来说是"新会话"，于是被一次确认整体隐藏。cc-web、jj 两个空间的任务手机早就打开过，所以没受影响。

## A. 别的设备新建的任务不再"消失"

### A1. 空间下显示"本机未打开"的任务（主修复）

- `spaces.load()` 本来就拉取了 `/api/sessions/list`。保留一个"服务端有、本机没打开"的集合（`remoteOnly`），在对应空间组里渲染成**淡色行**：任务名 + 小字"未在本设备打开"。
- **点击**（PC 单击，手机轻点）：`addTab` → `switchToTab`，同时从 `ignoredIds` 中移除。和在 Sessions 面板里点开是同一个效果，复用同一个函数，不另写一套。
- **从本设备隐藏**：淡色行的 `⋯` 菜单里有"在本设备隐藏"，写入 `ignoredIds`，并在空间组尾显示"另有 N 个已隐藏"，点开可以恢复。这样隐藏是看得见、可撤销的，不再是"消失"。
- 空间行计数和收起后左侧窄条上的空间徽标，都把淡色行计入（单独标"未打开 N"），收起状态下也能看出这个空间有内容。
- 水位线（SPACE-10）：淡色行排在已打开任务之后，计入"显示更多"。
- 搜索（SPACE-11）：命中淡色行时同样列出，点击即打开。

### A2. 恢复对话框的默认勾选（START-05 调整）

- 别的设备新建的会话（`extra`）**默认勾选**；本机曾主动隐藏的保持不勾选。
- 文案改为中文：「这些任务是在其他设备上新建的，默认会一起打开；不想在本设备显示的请取消勾选」。
- 有了 A1，即使取消勾选，任务也会以淡色行留在空间下，不会再"消失"。

### A3. 恢复对话框可以关闭（顺带解决 GAP-15）

- 加 ×、Esc、点背景三种关闭方式，关闭等于"暂不决定"：不写 `ignoredIds`，本机已有的标签照常恢复，新会话以淡色行出现在空间下。
- 手机上对话框沿用 MOB-13 的全宽卡片，底部按钮固定，触控区 ≥44px。

### A4. 在线时的同步

- 别的设备新建或删除会话时，服务端已有 `session_created` 推送，需要核实它能否到达**同一用户的所有连接**。到达后，本机直接以淡色行加入对应空间，不用等刷新。
- 会话在服务端被删除时，淡色行跟着移除；本机已打开的标签按现有逻辑处理。

### A 部分的 PC / 手机兼容要点

| 点 | PC | 手机 |
|---|---|---|
| 打开淡色行 | 单击 | 轻点；行高 ≥44px |
| 行菜单 | 右键菜单 + 悬停出现的 `⋯` | `⋯` **常驻显示**（不依赖悬停，同 FILE-12 的做法） |
| 打开后 | 侧栏保持 | 抽屉自动收起（沿用 MOB-11） |
| 本地状态 | `cc-web-tabs` 按设备各存一份，这点不变：每台设备自己决定打开哪些，但谁都能**看到**全部 | 同左 |

## B. 手机端 header 优化（只改 ≤768px 的样式，桌面不变）

### 目标

1. 320–430px 宽度下，header 所有控件都在屏内，**不出现横向溢出**，每个触控区 ≥44px。
2. 能看到**当前任务名**，这是现在最缺的信息。
3. 常用操作一步可达，不常用的收进菜单。

### 布局（≤480px）

```
┌──────────────────────────────────────────────┐
│ [≡]  市场调研推门户 ▾          [＋] [💬] [⚙] │
│      cgs-master                              │
└──────────────────────────────────────────────┘
  44    面包屑 flex:1，省略号截断    44   44   44
```

- **[≡]** = `sidebarToggleBtn`（MOB-11 抽屉开合），放在最左。
- **面包屑**：第一行任务名（粗、省略号截断），第二行小字显示空间名，不显示目录。点击打开侧栏抽屉并定位到当前任务。最小宽度在 360px 下 ≥120px。
- **[＋]**：新建任务，只显示图标，44px（NEW-01 入口不变，只是外观）。
- **[💬]**：会话列表 `historyBtn`（SES-01）。手机上找回会话最常用，保留在外面。
- **[⚙]**：`hamburgerBtn` 打开设置菜单（SET-01）。
- 隐藏 logo（≤480px），把宽度让给任务名。
- **收进 ⚙ 菜单**的：文件（`explorerBtn`，FILE-01）、分支（`branchBtn`，GIT-01）、账号（`accountHeaderBtn`，ACC-01）。菜单里放在最上面，图标加文字。**这三项是否移入菜单需要用户确认，见第 E 节。**

### 481–768px（大屏手机横屏 / 小平板）

保持一行，显示 logo 图标（不带文字），面包屑显示"空间 · 任务"，文件和分支按钮回到 header，账号只显示图标。宽度不够时按以下顺序收进菜单：分支 → 文件 → 账号，用 CSS 断点实现，不靠 JS 测宽。

### 其他

- `padding-left/right: max(8px, env(safe-area-inset-left/right))`，横屏刘海屏不遮按钮。
- header 高度在手机上固定 48px，避免内容变化导致终端行数抖动（与 MOB-09 一起验证）。
- 断点只用 CSS media query，和 MOB-17 的原则一致（不看设备判定）：PC 窗口拉窄会得到同样的布局，拉宽恢复。
- MOB-12 的描述改成与实现一致：齿轮在右侧。

## C. 桌面端兼容（不能变的东西）

- >768px：header、侧栏、恢复对话框的现有行为全部保持，只多出 A1 的淡色行和 A3 的关闭方式。
- 键盘：Ctrl+T、Alt+1..9 不把淡色行算进去（只数已打开的标签），避免快捷键编号随别的设备变化。
- 拖拽排序（SPACE-05）：淡色行不能拖，打开后才参与排序。
- 分屏（SPLIT-*）：淡色行不能拖进分屏，打开后才可以。
